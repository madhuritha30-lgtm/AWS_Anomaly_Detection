# AWS Anomaly Detection

## About the Project

AWS Anomaly Detection is an AI/ML-based system designed to detect abnormal patterns in weather data collected from Automatic Weather Stations.

## Features

- Weather data analysis
- Anomaly detection
- Data visualization
- Machine learning-based analysis
- Automatic Weather Station data processing

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Data Visualization
- AWS Weather Data

## Dataset

The project uses weather data from Automatic Weather Stations for analysis and anomaly detection.

## Project Structure

- `app` – Main application source files
- `generate_data` – Data generation/source files
- `aws_weather_data.csv` – Weather dataset
- `.gitattributes` – Git configuration

## Objective

The main objective of this project is to identify unusual weather patterns or abnormal sensor readings using machine learning techniques.

## Future Scope

- Real-time weather monitoring
- Cloud-based deployment
- Improved anomaly detection models
- Alerts for abnormal weather conditions
